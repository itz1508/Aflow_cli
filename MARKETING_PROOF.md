- A-Flow preserves the submitted plan and produces an additive companion package.
- A live operation used Ollama with `qwen2.5-coder:7b`; fallback was false.
- Semantic observations became explicitly unresolved advisory gaps until repository evidence existed.

## Known limitations

- Docker build, model setup, restart persistence, and container MCP proof are not current evidence because Docker Desktop's Linux engine was unavailable.
- External video, YouTube, Devpost, repository-access, and session-ID submission actions are outside this repository operation.
- Stale evidence detection uses existence, size, modification time, and platform file identity; content hashes are not foregrounded.

## Excluded claims

A-Flow does not claim to find every conceivable gap, replace the coding agent, provide an automatic lifecycle hook on every host, or prove Docker/cloud/submission behavior without corresponding evidence.
